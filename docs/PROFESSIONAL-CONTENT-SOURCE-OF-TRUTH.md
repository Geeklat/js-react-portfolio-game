# Professional Content Source of Truth

## Purpose

This document defines the approved professional-content sources and
content-handling rules for the portfolio.

It exists to prevent generated or inferred resume content from entering
the application and to ensure that the portfolio consistently represents
the professional direction intended by the repository owner.

This file governs:

- Profile content
- Work / professional experience
- Skills
- Contact information
- Professional positioning
- Career motivations when relevant
- Resume-related descriptive copy

It does not require the portfolio to reproduce the full resume verbatim.

The website may select, summarize, reorganize, or present verified
professional material differently when doing so improves the portfolio
experience without changing the underlying facts.

---

# Source Authority

Professional information should be resolved using the following precedence.

## 1. Master Resume — Primary Factual Authority

The master resume is the authoritative source for:

- Employers
- Job titles
- Employment dates
- Education
- Technologies
- Responsibilities
- Accomplishments
- Metrics
- Professional skills
- Verified work-history claims

Source document:

`local-source/Justin_Green_Master_Resume.md`

When another source differs from the master resume, use the master resume
unless the human owner explicitly approves a change.

Do not silently reconcile discrepancies.

Surface meaningful conflicts for human review.

---

## 2. Cover Letter Source of Truth — Professional Motivation and Voice

The cover-letter source of truth is authoritative for approved statements
about:

- Professional motivations
- Career direction
- Work preferences
- Engineering interests
- Adaptability
- UX motivation
- Accessibility motivation
- AI-assisted engineering philosophy
- Cross-team translation
- Product-oriented career goals
- Approved professional characteristics
- Sensitive-information boundaries

Source document:

`local-source/COVER_LETTER_SOURCE_OF_TRUTH.md`

This source may provide context that does not belong as a resume bullet
but can help write a more natural Profile section.

It must not be used to create new factual work-history claims.

## 3. LinkedIn Profile — Secondary Consistency Reference

The LinkedIn profile may be used to:

- Compare public-facing terminology
- Check presentation consistency
- Identify wording worth reviewing
- Confirm public contact information
- Review how experience is currently presented publicly

Source document:

LinkedIn does not override the master resume.

If LinkedIn and the master resume disagree about a title, date,
responsibility, technology, or accomplishment, retain the master-resume

# Work Content Transformation Rules

The website is not required to duplicate resume prose.

Approved transformations include:

- Shortening a resume bullet
- Combining closely related verified bullets
- Reformatting information for a UI card or menu screen
- Separating responsibilities from outcomes
- Highlighting selected technologies
- Reordering verified accomplishments to improve readability
- Using shorter summaries on small screens
- Presenting additional verified detail that does not fit the PDF resume

These transformations are acceptable only when factual meaning remains
unchanged.

Do not transform:

> Contributed to technical planning

into:

> Led architecture strategy

unless the stronger statement is independently supported by the approved
source material.

# Conflicting Sources

When approved sources conflict:

1. Prefer the Master Resume for factual employment information.
2. Use the Cover Letter Source of Truth for motivation, voice, and approved
   professional characteristics.
3. Treat LinkedIn as a secondary public-presentation reference.
4. Do not silently merge contradictory claims.
5. Surface meaningful discrepancies for human review.

Once the human owner resolves a discrepancy, update the appropriate
authoritative source rather than creating a portfolio-only correction
when practical.

# Human Review Required

Stop for human review before:

- materially changing the professional positioning,
- deciding that an experience should be omitted because it seems irrelevant,
- adding unsupported professional claims,
- resolving discrepancies between source documents,
- substantially rewriting achievements,
- introducing personal information,
- changing public contact information,
- or changing which skills are emphasized in a way that materially changes
  the professional narrative.

Formatting already-approved material does not require separate approval.

# Update Policy

This document summarizes how approved professional source material may be
used.

It should evolve when the underlying source-of-truth documents change.

When employment history, skills, professional direction, or approved
motivations change:

1. Update the appropriate authoritative source.
2. Update this document if its guidance is affected.
3. Update portfolio content derived from that source.

Do not allow the portfolio implementation itself to become the only place
where a professional fact exists.
